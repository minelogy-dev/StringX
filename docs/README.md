# String X documentation

String X is a small C string library with a single-header API (`<sx.h>`) and a
byte-exact, zero-copy view model. This directory holds the complete
documentation for **v0.5**, in English and Simplified Chinese.

Choose a language / 选择语言:

- **[English documentation](en_us/README.md)**
- **[简体中文文档](zh_cn/README.md)**
